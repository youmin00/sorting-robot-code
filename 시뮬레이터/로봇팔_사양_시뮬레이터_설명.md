# 4축 로봇팔 사양 시뮬레이터

`로봇팔_사양_시뮬레이터.html`을 Chrome 또는 Edge에서 열면 설치 없이 실행됩니다.

## 반영된 사양

- J1 0–180°, J2 0–180°, J3 모터 0–90°, J4 0–180°
- J3 조립 오프셋 +30° (유효각 30–120°)
- L1/L2 = 130 mm, L3 = 76 mm (벨로우즈 압축 시 68 mm)
- 벨트 상판 기준 J1 = 6.3 mm, J2 = 51.3 mm
- 한쪽 작업영역 X = 110–215 mm, Y = -150–150 mm
- 좌표계: +X 벨트 안쪽, +Y 벨트 진행, +Z 위쪽

## 기능

- 4개 관절과 벨로우즈 압축량 조작
- 3D 등각/윗면/측면/정면 동시 표시
- 목표 좌표에 대한 제한조건 포함 수치 역기구학
- 컨베이어 진행 애니메이션과 이론 작업영역 표시
- 3 cm/5 cm 정육면체 선택 및 실제 크기 표시
- 로딩 자세 → 수직 접근 → 상판 접촉 → 벨로우즈 최대 8 mm 수축 → 흡착 → 수직 60 mm 상승 → 로딩 자세 자동 동작
- 물체 좌표는 벨트 상판을 Z=0으로 한 큐브 바닥 중심 좌표
- 로딩 자세: J1=90°, J2=120°, J3=56°, J4=0°
- `집기 정렬` 버튼은 움직임 애니메이션 없이 수직 집기 자세를 즉시 만들며 벨로우즈는 수축하지 않음
- `벨트에 놓기` 버튼은 큐브 바닥 높이를 항상 Z=0으로 배치
- 카메라 좌표 입력 UI는 cm 단위이며 소수점 첫째 자리까지 입력
- Camera `(0.0,0.0,0.0) cm`을 Robot `(210,0,0) mm`으로 변환
- 내부 변환식: `Robot X(mm) = Camera X(cm) × 10 + 210`, `Robot Y(mm) = Camera Y(cm) × 10`
- Camera Z가 0이면 선택한 큐브 크기(30/50 mm)를 상판 높이로 사용
- 랜덤 위치 버튼은 큐브 전체가 X=110–215, Y=-150–150 mm 경계선에서 최소 1 mm 이상 떨어지도록 배치
- 직접 입력한 좌표도 큐브 외곽이 작업영역 경계선에 닿으면 집기와 집기 정렬을 차단
- 벨트 버튼 대신 윗면 도면에 고정된 `+Y 벨트 진행` 화살표 표시

## 모델링 가정

기본 자세는 J1/J2/J3/J4 모두 90°입니다. J3는 0° 위치를 조립 기준 위치로 유지하며, 모터각이 0°에서 90°로 증가할 때 Link 2가 음의 피치 방향으로 회전하도록 반영했습니다. 화면의 J3 유효각 표시는 조립 오프셋을 포함해 `모터각 + 30°`로 표시됩니다.
