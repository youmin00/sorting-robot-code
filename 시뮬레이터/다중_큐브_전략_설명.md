# 4큐브 피킹 전략 예비 시뮬레이터

`다중_큐브_전략_시뮬레이터.html`을 브라우저에서 열면 실행됩니다. 기존 단일 큐브 로봇팔 시뮬레이터와 독립된 비교 실험용 파일입니다.

- 3 cm 큐브 2개, 5 cm 큐브 2개를 겹치지 않게 랜덤 배치
- 각 큐브를 0~90° 범위에서 무작위 회전하며, 회전된 네 모서리가 작업영역 안에 있도록 배치
- 가까운 순서 / 수직 집기 가능한 가까운 순서 / 직선 통로 우선 전략 비교
- 접근 높이와 상승 높이를 변경해 전략별 결과 확인
- 1단계 피킹, 전체 자동 피킹, 동일 조건 100회 비교
- 실패 원인을 접근·접촉·압축·상승 단계별 위치 오차로 표시

현재 기본 조건은 Y=-120~120 mm, 접근 10 mm, 상승 20 mm, `수직 집기 가능한 큐브 중 가장 가까운 큐브` 우선입니다.

벨트 기준 좌표는 `Camera X=벨트 X(진행 방향)`, `Camera Y=벨트 Y(중앙선 0)`입니다. 먼저 사용하는 로봇은 카메라 +Y 쪽에 설치되고 카메라 -Y 방향으로 접근합니다. 내부 IK 좌표는 `전방거리 = 210 - camera robot_y_mm`, `측방향 = camera robot_x_mm`, `Z = camera robot_z_mm`로 변환합니다. 브라우저 연결부에서는 단일 객체는 `setCameraObject(object)`, 다중 객체 배열은 `setCameraObjects(objects)`로 전달할 수 있습니다.

직선 통로 검사는 완전한 3D 충돌 회피가 아니라, 전략 선정 기준을 잡기 위한 2D 근사 검사입니다.
