# RealSense 기반 양팔 자동 분류 로봇

Intel RealSense D435의 컬러·깊이 영상을 사용해 큐브를 인식하고, STM32 기반 양팔 로봇·공압 그리퍼·컨베이어를 제어하는 하드웨어 통합 프로젝트입니다.

이 저장소는 실제 장비 제어 코드와 함께, 역기구학·검출 안정화·작업 통계·시뮬레이터를 포함합니다.

## 프로젝트 흐름

1. RealSense D435에서 컬러/깊이 프레임을 수집합니다.
2. 물체 후보의 위치와 높이를 추정하고, 프레임 간 안정성을 확인합니다.
3. PC에서 양팔의 역기구학과 충돌·작업영역 조건을 검증합니다.
4. STM32로 동작 계획을 전송해 로봇팔, 공압 그리퍼, 컨베이어를 제어합니다.
5. 픽업 결과를 다시 관측해 성공·실패·보류 상태를 통계로 기록합니다.

## 구현 포인트

- 깊이 기반 물체 검출과 프레임 간 좌표 안정화
- 양팔 역기구학, 작업영역 판정, 안전한 시리얼 명령 전송
- 픽업 후 재관측을 통한 성공 여부 검증 및 세션 통계
- 단일/다중 큐브 전략과 로봇팔 작업영역 시뮬레이터
- Python 상위 제어와 STM32 펌웨어 간 UART 통신

## 구성

| 경로 | 역할 |
| --- | --- |
| `통합_자동분류_실행.py` | 카메라·양팔·컨베이어를 연결하는 메인 제어 프로그램 |
| `sorting_robot/` | 역기구학, 통신, 비전 보조 함수, 작업 통계 모듈 |
| `STM32_제어코드/` | 로봇팔 및 컨베이어 STM32 펌웨어 |
| `tests/` | 하드웨어 없이 실행 가능한 핵심 로직 회귀 테스트 |
| `시뮬레이터/` | 작업영역과 다중 큐브 전략을 확인하는 브라우저 기반 도구 |
| `도구/` | 좌표 안정성·속도 측정 등 개발 진단 도구 |

## 개발 환경

- Windows, Python 3.12
- Intel RealSense D435
- STM32 기반 로봇팔 제어 보드 및 컨베이어 제어 보드
- Python: OpenCV, NumPy, pyrealsense2, Pillow, pyserial

## 설치 및 실행

```powershell
py -3.12 -m venv .venv312
.\.venv312\Scripts\python.exe -m pip install -r requirements.txt
.\통합_자동분류_실행.bat
```

또는 Python으로 직접 실행합니다.

```powershell
.\.venv312\Scripts\python.exe .\통합_자동분류_실행.py
```

기본 통신 설정은 로봇팔 `COM3`, 컨베이어 `COM4`, 115200 baud입니다. 실제 장비 구성에 맞게 메인 프로그램의 `ROBOT_ARM_PORT`와 `STM32_PORT`를 변경해야 합니다.

> 실제 하드웨어를 구동하기 전에는 주변 안전을 확인하고, CubeIDE Serial Terminal·RealSense Viewer 등 포트를 점유할 수 있는 프로그램을 종료하세요.

## 검증

카메라와 로봇 없이 핵심 로직을 검증하려면 다음을 실행합니다.

```powershell
.\.venv312\Scripts\python.exe -m unittest discover -s tests -v
```

## 포트폴리오 범위

이 프로젝트는 실제 제작한 하드웨어와 연결해 동작하도록 설계되었습니다. 장비가 없는 환경에서도 코드 구조, 테스트, 그리고 `시뮬레이터/`의 브라우저 도구를 통해 주요 제어 로직과 설계 의도를 확인할 수 있습니다. 로컬 캡처 데이터, 가상환경, 장치 유틸리티 실행 파일은 저장소에 포함하지 않습니다.
